아주산업 1호 공급계약 &
CogniCraft 도면·여권 실증

2026년 4월 20일 체결된 아주산업 정식 공급계약(1.1억 원)의 CogniBoard v0.16.2 실가동 관제 시스템과
2D 도면(도면 296)에서 3D CAD 솔리드 복원·ATP v1.0 성적서·Part Passport로 이어지는 완결형 기술 실증 사례입니다.

프로젝트 개요 (Project Details)

주식회사 액사이드(AXIDE Inc.)는 2026년 4월 20일 중견 건설·건자재 선도기업 아주산업과 1호 정식 공급계약(계약금액 110,000,000원, 부가세 포함)을 체결하고, 사내 폐쇄망 인프라에 에어갭 소버린 AI 운영체제 Cogni-OS와 실시간 오케스트레이션 관제 보드 CogniBoard v0.16.2를 구축했습니다. 상단 이미지는 실제 가동 중인 CogniBoard v0.16.2 화면으로, 좌측 도메인 트리(01_기획·전략, 02_인사·총무, 03_재무·회계, 04_마케팅·세일즈, 05_개발·IT, 06_법무·감사, 07_고객지원·CS, 99_시스템·공통)와 중앙 에이전트 토폴로지 맵, 우측 태스크 실행 큐(Running 42 / Queued 311 / Done 514 / Denied 12)가 단일 콘솔에서 통제됩니다.

외부 클라우드 LLM API를 일절 호출하지 않는 순수 내부망 환경(Outbound 0 Byte)에서 사내 기술 표준서, 배합 설계 문서, 설비 보전 이력, 법무·감사 규정을 멀티에이전트 합의로 처리하며, 모든 에이전트의 실행 결과는 SHA-256 해시 체인으로 봉인되어 위·변조가 불가능한 감사 증거로 남습니다. 3개월간의 본사 실증을 마친 뒤 아주그룹 지주 및 계열사로의 확산을 추진하고 있습니다.

DELIVERABLES (핵심 구축 산출물)
Cogni-OS Air-Gap Core CogniBoard v0.16.2 CogniCraft 2D→3D CAD Part Passport v1.0 ATP v1.0 성적서
INDUSTRY (적용 산업군)
중견 제조 · 방위산업 공급망

현장 1시간 설치 & 에어갭 아키텍처 (Project Research)

전담 IT 인력이 부족한 제조 공장 및 방산 2·3차 협력사 현장의 도입 장벽을 없애기 위해, AXIDE는 방진·방습 Pelican 1510 케이스에 사내 구축형 고성능 GPU 워크스테이션, YubiKey 5 FIPS 하드웨어 보안키 2개, 산업용 QR 스캐너와 라벨 프린터를 올인원으로 패키징한 AXIDE Field Vault를 설계했습니다. 현장 도착 후 전원만 연결하면 1시간 이내에 인터넷이 완전히 차단된 에어갭 AI 노드가 가동됩니다.

내부 추론 엔진은 8대의 NVIDIA B200 GPU 클러스터에서 64,615건의 SFT/DPO 제조·방산 데이터셋으로 파인튜닝된 오픈웨이트 모델(Qwen3.5-9B / 27B / 35B-A3B MoE)을 구동하며, 사내 코딩 및 도면·규격 추론 벤치마크 93.3점(외부 API 대비 110% 성능), p95 추론 응답 240ms, 감사 추적 상관율 99.1%를 달성했습니다.

실증 결과: 2D 도면 296 → 3D 솔리드 복원 & ATP v1.0 (Project Results)

하단 좌측 이미지는 실제 제조·방산 현장의 2D 삼각법 기계제도 도면(도면 296)이며, 우측 이미지는 CogniCraft 엔진이 폐쇄망 내부에서 정면도·평면도·우측면도의 치수선, 은선, 구멍·슬롯 형상 및 GD&T 기하공차를 자동 판독해 복원한 3D 파라메트릭 CAD 솔리드 모델입니다. 복원된 3D STEP/IGES 모델은 공구 경로(G-code) 생성과 함께 즉시 ATP(Acceptance Test Procedure) v1.0 자동 인수시험 성적서의 기준값으로 변환됩니다. 가공 완료된 알루미늄 6061 부품은 로보티즈 OMY-F3M 6자유도 측정 루프를 거쳐 실측 편차가 기록되고, 작업자 YubiKey 서명 후 Part Passport v1.0이 발행되어 원청 입고 시 단 3초 만에 위·변조 여부가 검증됩니다.
