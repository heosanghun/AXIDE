특허 등록된 DEQ 고정점 추론 런타임, 결정론적 3D CAD 파서, Ed25519·SHA256 감사 봉인 엔진, 그리고 IP67 Field Vault 패키지로 구성됩니다.

1층: Cogni-OS Core — 검수(ATP) 통과 폐쇄망 추론 런타임 · DEQ & Edge0 연구 엔진
검수 관문(ATP)을 통과한 엔진만 탑재하는 교체형 폐쇄망 추론 런타임입니다. 1호기는 검증된 Gemma 4 + 기하 검증 + Tech-Audit으로 구동되며(2026.10 오프라인 노트북 gemma-4-e4b-it bf16 30회 실측 VRAM 14.8GB, TTFT 중앙값 0.161초 · 검증 보고서 요청 가능), 차세대 연구 엔진인 DEQ(심층 평형)와 Edge0-CUDA(SSD 전문가 스트리밍)는 관문 통과 순서대로 갱신 엔진에 투입됩니다. 확신이 부족할 때는 거짓 환각 대신 '판단 보류(모른다)'를 출력하고 로그에 남깁니다.
특허 제10-2973709호 TTFT 0.161초 · VRAM 14.8GB (검증 원장 보유) 미확신·미수렴 시 판단 보류

2층: CogniCraft (1호기 계약명 System 4) — 3D CAD 파싱 & AR 스마트글라스 3줄 HUD
2D 기계제도 도면(DWG)과 3D 형상 모델(STEP·STL·메시)을 외부 클라우드 전송 없이 로컬에서 직접 파싱하여 외경, 내경, 공차, 구멍 수, 부피, 단면도(SECTION A-A/B-B), BOM, 가공 공정표를 자동 생성합니다. 작업자는 로키드(Rokid) AR 스마트글라스의 3줄 핵심 요약 HUD와 한국어 음성 명령, 갤럭시 탭 S11 울트라를 통해 기름 묻은 장갑을 낀 채로 도면을 제어할 수 있습니다.
STEP·DWG·STL 결정론적 파싱 로키드 AR 글라스 3줄 HUD 음성·대화형 3D 치수 편집

3층: Tech-Audit — Ed25519 전자서명 & SHA256 해시 체인 감사 봉인
방위산업기술 보호법(법률 제21768호), 국가망보안체계(N2SF), AI 기본법, 금융 망분리 감사를 통과하기 위한 핵심 증거 계층입니다. 입력 도면 해시, AI 모델 가중치 해시, 환경 매니페스트, 추론 궤적 로그를 SHA256 해시 체인으로 엮고 Ed25519 전자서명으로 봉인합니다. NVIDIA B200 GPU에서 수행한 SFT→DPO 2단계 재학습으로 방산 감사 보고서 선호 정확도 96.7%를 달성했습니다.
Ed25519 전자서명 + SHA256 체인 오프라인 변조 줄 번호 즉시 탐지 B200 DPO 선호 정확도 96.7%

Part Passport & Field Vault — 방산 부품 여권 & 6종 하드웨어 금고
공장 안의 봉인을 원청 체계업체 ↔ 1차 협력사 ↔ 2차 정밀가공사 공급망 표준으로 확장한 '방산 부품 여권(Part Passport Spec v1)'입니다. 도면 원본을 외부로 반출하지 않고도 정본 도면 해시·AI 모델 해시·측정 결과를 하드웨어 바인딩 USB 보안 동글에 담아 부품과 함께 납품하며, IP67 방진·방수 케이스 2개(Field Vault)로 현장에 1시간 내 설치됩니다.

CYBER RISK × COGNI-OS · INTERNAL AI ARCHITECTURE

외부 연결은 줄이고, 핵심 데이터는 내부에서 통제합니다

① 내부 AI 실행(업무 데이터는 공장 안에서 처리) · ② 도면 접근 통제(하드웨어 키로 사용 권한 관리) · ③ 승인·기록(반입과 반출을 승인하고 이력을 보관)의 3단계 원칙으로 외부 유출 경로를 차단합니다.

CORE 4 TECHNOLOGIES · SINGLE-GPU SOVEREIGN ENGINE

단일 GPU 폐쇄망을 완성한 4대 핵심 기술

단일 32GB GPU 폐쇄망 환경에서 거대 모델의 추론 성능을 구현하는 ① 심층 평형(DEQ), ② NVMe 직통 스트리밍, ③ 자율 설계 에이전트(ADAS), ④ 이중 프로세스(System 1·2) OS입니다.

CORE TECHNOLOGY 01 · DEEP EQUILIBRIUM MODEL (DEQ)

① 평형(DEQ) 사고 엔진: 상수(O(1)) 메모리 심층 추론

단일 블록을 반복 적용해 고정점(z*)에 수렴시킴으로써 추론이 깊어져도 메모리를 상수(O(1))로 고정합니다.

CORE TECHNOLOGY 02 · PREDICTIVE NVMe-TO-GPU STREAMING

② 예측형 모듈 스트리밍: NVMe → GPU 직통 선적재

가중치를 모듈 단위로 분할해 시스템 RAM 경유 없이 PCIe 직통 경로로 GPU VRAM에 선적재합니다.

CORE TECHNOLOGY 03 · ADAS SELF-EVOLVING ARCHIVE

③ 자율 설계 아카이브(ADAS): 스스로 진화하는 에이전트

메타 에이전트가 하위 모듈을 생성·격리 검증·보관하며 세대마다 성능을 높이고 새 임무에 즉시 대응합니다.

CORE TECHNOLOGY 04 · DUAL-PROCESS OS & TWO LOOPS

④ 이중 프로세스 OS: 실행 루프(오늘)와 진화 루프(내일)

즉답은 빠른 System 1이 처리하고, 불확실한 질의는 System 2 심층 검토 및 사람 승인 후 지식 증류로 학습합니다.

자주 묻는 질문
DEQ 상수 메모리 O(1) 추론 구조 덕분에 기본 모델 적재 시 GPU 메모리 점유율이 14.8GB에 불과합니다. 따라서 단일 32GB GPU 워크스테이션 1대로 보안구역 내 선반·CNC 라인의 태블릿 및 AR 스마트글라스 다중 세션을 지연 없이(TTFT 중앙값 0.161초) 처리할 수 있습니다.
CogniCraft(1호기 계약명 System 4)는 방산·정밀가공 현장에서 표준으로 쓰이는 STEP(.stp/.step), IGES, STL, OBJ 등 3D 솔리드·메시 포맷과 DWG, DXF, PDF 기계제도 도면을 모두 로컬에서 직접 적재·파싱하며, 대화형 치수 수정 후 STEP/STL로 즉시 재내보내기가 가능합니다. (※ 차세대 연구 로드맵의 System 4(PCAS)는 무기울기 현장 센서 적응 엔진을 지칭합니다.)
매 추론 이벤트마다 [이전 레코드 해시 + 입력 도면 SHA256 + 모델 가중치 SHA256 + 추론 결과 + 타임스탬프]를 연쇄 해싱하고 하드웨어 보안 동글의 개인키로 Ed25519 전자서명을 남깁니다. 누군가 사후에 로그 파일의 숫자 한 글자만 수정해도 해당 줄의 해시와 이후 체인이 깨지며, 오프라인 검증기가 즉시 변조된 줄 번호를 출력합니다.
Field Vault 패키지에는 메인 단일 32GB GPU 워크스테이션 외에도 즉시 페일오버(Failover) 기동이 가능한 고성능 이동형 서버 노트북(ASUS ROG Strix SCAR 18, RTX 5090)이 함께 포함되어 있어, 장비 점검 중에도 현장 작업이 중단되지 않습니다.
